# Student Performance Analysis & Prediction

### A Data Science and Machine Learning Project

This project analyzes student academic performance using Python, data analysis, data visualization, and machine learning techniques. It explores how attendance, study habits, revision, assignments, quizzes, and midterm scores relate to students' final academic performance.

## Project Overview

The project uses a dataset of 500 student records to identify academic performance patterns and build machine learning models for prediction.

## Objectives

- Analyze student academic performance.
- Study the relationship between attendance and final scores.
- Understand the impact of study hours and regular revision.
- Perform data cleaning and preprocessing.
- Visualize academic performance patterns.
- Predict final scores using Linear Regression.
- Classify Pass/Fail results using Random Forest.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Visualizations

The notebook includes visual analysis such as:

- Final Score Distribution
- Attendance vs Final Score
- Study Hours vs Final Score
- Regular Revision Impact
- Attendance Level Analysis
- Grade Distribution
- Correlation Heatmap

## Machine Learning Models

**1. Linear Regression**

Used to predict students' final scores based on academic and study-related features.

**2. Random Forest Classifier**

Used to classify student results into Pass or Fail.

## Dataset Information

- Total Records: 500
- Student academic and study-related attributes
- Attendance, study hours, sleep hours, assignments, quizzes, and midterm scores

Note: The notebook generates a sample dataset using Python rather than loading an external real-world dataset.
